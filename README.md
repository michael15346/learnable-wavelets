# Обучаемые вейвлеты
## Общая информация

Автор: Задорский М. С.

Научный руководитель: Бабушкин М. В.
## Тема
Разработка нейросетевого метода сжатия изображений, основанного на обучаемых несепарабельных всплеск-преобразованиях
## План работ
1. Разработать метод обучения всплеск-преобразований произвольного вида при условии фиксированного набора матриц растяжения. (апрель 2027)
2. Провести замеры производительности полученного метода по сравнению с baseline. (май 2027)
3. Разработать метод обучения матриц растяжения несепарабельных всплеск-преобразований. (ноябрь 2027)
4. Провести замеры производительности нового метода в сравнении с методом из п. 2) и baseline. (декабрь 2027)
5. Эвристические улучшения и формализация результатов (апрель 2028)
